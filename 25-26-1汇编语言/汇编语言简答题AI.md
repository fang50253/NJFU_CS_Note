# 汇编语言课程复习简答题

## 第一章：绪论
1. **为什么要学习汇编语言？**  
   学习汇编语言可以深入理解计算机底层工作原理，为学习操作系统、计算机组成等课程打下基础，同时也是开发驱动程序、嵌入式系统等底层应用的基础。

2. **机器语言和汇编语言的主要区别是什么？**  
   机器语言是二进制指令，难以理解和编写；汇编语言是机器指令的助记符，便于记忆和编写。

3. **8086CPU的地址总线和数据总线宽度分别是多少？其寻址能力是多少？**  
   地址总线宽度为20位，数据总线宽度为16位；寻址能力为1MB。

4. **什么是内存地址空间？8086CPU的内存地址空间是多大？**  
   内存地址空间是CPU可以寻址的内存范围；8086CPU的内存地址空间为1MB。

5. **8086CPU中的寄存器有哪些类型？各举两个例子。**  
   通用寄存器（AX、BX）、段寄存器（CS、DS）、指针寄存器（IP、SP）、标志寄存器（PSW）。

---

## 第二章：访问寄存器和内存
6. **MOV指令的基本格式是什么？举例说明。**  
   MOV dest, src；如 MOV AX, 1234H。

7. **ADD指令的基本格式是什么？举例说明。**  
   ADD dest, src；如 ADD AX, BX。

8. **8086CPU如何将两个16位地址合成一个20位的物理地址？**  
   物理地址 = 段地址 × 16 + 偏移地址。

9. **什么是内存的分段表示法？**  
   将内存划分为若干个逻辑段，每个段由段地址和偏移地址组合来访问。

10. **Debug工具中，R、D、E、U、A、T命令分别有什么功能？**  
    R：查看/修改寄存器；D：查看内存；E：修改内存；U：反汇编；A：写入汇编指令；T：单步执行。

11. **CS和IP寄存器的作用是什么？**  
    CS存放代码段的段地址，IP存放下一条指令的偏移地址。

12. **JMP指令有哪些格式？各用于什么场景？**  
    JMP 标号（短转移）；JMP 寄存器（段内转移）；JMP 段地址:偏移地址（段间转移）。

13. **什么是字单元？如何存储？**  
   字单元由两个连续字节组成，低地址存低字节，高地址存高字节。

14. **如何用DS和[address]访问内存中的数据？举例说明。**  
    MOV AX, [0]；默认段地址在DS中。

15. **栈的基本操作有哪些？栈顶由哪两个寄存器指示？**  
   入栈（PUSH）和出栈（POP）；栈顶由SS和SP指示。

## 第三章：汇编语言程序
16. **汇编语言源程序的基本结构包括哪些部分？**  
   段定义（segment/ends）、段寄存器关联（assume）、程序入口标号、程序结束（end）。

17. **伪指令和汇编指令有什么区别？**  
   伪指令由编译器处理，不生成机器码；汇编指令对应机器码，由CPU执行。

18. **什么是标号？在程序中起什么作用？**  
   标号表示一个地址，常用于跳转或循环。

19. **LOOP指令的作用是什么？使用条件是什么？**  
   用于循环，执行 (CX)=(CX)-1，若 CX≠0 则跳转到标号处。

20. **如何在代码段中定义和使用数据？**  
   使用 dw/db 定义数据，通过 CS:[偏移地址] 访问。

21. **如何将数据、代码、栈放入不同的段？**  
   分别用 segment/ends 定义不同段，用 assume 关联段寄存器。

## 第四章：内存寻址方式
22. **[bx+idata]、[bx+si]、[bx+si+idata] 分别表示什么寻址方式？**  
   [bx+idata]：基址+偏移；[bx+si]：基址+变址；[bx+si+idata]：基址+变址+偏移。

23. **SI和DI寄存器与BX寄存器在寻址中有什么区别？**  
   BX可拆分为BH/BL，SI和DI不能拆分。

24. **and 和 or 指令分别用于什么操作？举例说明。**  
   and 用于按位与，如将某位清零；or 用于按位或，如将某位置1。

25. **什么是段前缀？有什么作用？**  
   段前缀如 ds:、es:，用于显式指定段地址，避免段寄存器默认值错误。

26. **如何用div指令进行除法运算？举例说明。**  
   div 除数；如 div bl，被除数在AX中，商在AL，余数在AH。

## 第五章：流程转移与子程序
27. **JMP指令的分类有哪些？各用于什么场景？**  
   段内短转移（jmp short）、段内近转移（jmp near）、段间转移（jmp far）。

28. **jcxz指令的作用是什么？使用条件是什么？**  
   若 CX=0 则跳转；常用于循环前的条件判断。

29. **什么是位移转移？有什么优点？**  
   根据相对位移进行跳转，不依赖于绝对地址，便于程序重定位。

30. **call 和 ret 指令的作用是什么？**  
   call 用于调用子程序，保存返回地址；ret 用于返回调用处。

31. **ret和retf指令的主要区别是什么？**  
    ret用于近返回，只修改IP；retf用于远返回，同时修改CS和IP。

    - call far ptr 标号（段间转移）
    - call 16位寄存器（转移地址在寄存器中）
    - call word ptr/dword ptr 内存单元（转移地址在内存中）

34. **如何用call和ret指令实现子程序调用与返回？**  
    call指令跳转到子程序入口，子程序执行完毕后用ret指令返回调用处。

35. **mul指令用于什么运算？结果如何存放？**  
    mul用于乘法运算。若为8位乘法，结果在AX中；若为16位乘法，结果在DX（高位）和AX（低位）中。

36. **在子程序中如何传递参数和返回值？**  
    常用寄存器传递，如用BX传递参数，DX:AX存放返回值。

37. **什么是寄存器冲突？如何避免？**  
    当主程序和子程序使用同一寄存器时会发生冲突。避免方法：在子程序开始将所用寄存器入栈，结束时出栈。

38. **什么是标志寄存器（flag）？常用的标志位有哪些？**  
    标志寄存器用于记录CPU运算状态。常用标志位：ZF（零标志）、PF（奇偶标志）、SF（符号标志）、CF（进位标志）、OF（溢出标志）。

39. **adc指令和sbb指令分别用于什么运算？**  
    adc用于带进位加法，sbb用于带借位减法。两者常用于多字节（大数）运算。

40. **CF和OF标志位有什么区别？**  
    CF用于无符号数运算，记录进位/借位；OF用于有符号数运算，记录是否溢出。

41. **`cmp` 指令的功能是什么？它与 `sub` 指令的主要区别在哪里？**  
	`cmp` 指令用于比较两个操作数，相当于执行减法操作但不保存结果，仅根据计算结果设置标志寄存器。与 `sub` 指令的主要区别在于 `cmp` 不改变操作数的值，只影响标志位。

42. **请解释在执行 `cmp ah, bh` 后，如果 ZF=1 和 ZF=0 分别表示什么比较结果？**  
	若 ZF=1，表示 `(ah) = (bh)`；若 ZF=0，表示 `(ah) ≠ (bh)`。

43. **在有符号数比较中，为什么仅凭 SF 标志位不能判断大小关系？请举例说明。**  
	因为 SF 记录的是运算结果在计算机中的表示是否为正负，可能因溢出而导致与实际逻辑结果不一致。例如 `(ah)=22H, (bh)=0A0H` 比较时，SF=1，但实际 `34 > -96`。

44. **请写出 `je` 和 `jne` 指令的全称及其检测的标志位。**  
	`je`（jump if equal）检测 ZF=1；`jne`（jump if not equal）检测 ZF=0。

45. **串传送指令 `movsb` 和 `movsw` 的区别是什么？它们如何与 `rep` 指令配合使用？**  
	`movsb` 以字节为单位传送，`movsw` 以字为单位传送。`rep` 指令根据 CX 的值重复执行后面的串传送指令，实现连续传送。

# 汇编语言原理性简答题（含详细解答）

## 一、堆栈与子程序机制

**1. 请详细说明8086CPU中栈的工作原理，包括栈顶指针（SP）的变化规则、入栈（PUSH）和出栈（POP）操作的具体执行过程，并解释“后进先出”（LIFO）原则如何体现。**

> **解答：**  
> 8086CPU中，栈是一段特殊的内存空间，通过SS段寄存器和SP栈顶指针寄存器共同管理。栈顶始终由SS:SP指向当前栈顶元素。  
> **入栈过程（PUSH AX为例）：**  
> 1. SP = SP - 2（栈向低地址增长）
> 2. 将AX的值写入SS:SP指向的字单元
> 3. SS:SP指向新的栈顶
> **出栈过程（POP BX为例）：**  
> 1. 将SS:SP指向的字单元数据读入BX
> 2. SP = SP + 2
> 3. SS:SP指向新栈顶（原栈顶下方）
> **LIFO体现：** 最后入栈的数据位于栈顶，出栈时最先被取出。例如依次PUSH AX、BX、CX后，POP顺序为CX、BX、AX，实现“后进先出”的数据访问顺序。

---

**2. 解释CALL和RET指令如何配合实现子程序调用与返回机制，包括堆栈在其中的关键作用。**

> **解答：**  
> **CALL指令执行时：**  
> 1. 将下一条指令的IP（近调用）或CS:IP（远调用）压栈保存返回地址
> 2. 跳转到子程序入口地址
> **子程序执行期间：** 通过栈保存局部数据、寄存器值
> **RET指令执行时：**  
> 1. 从栈顶弹出返回地址到IP（近返回）或CS:IP（远返回）
> 2. SP相应调整
> **关键作用：** 栈作为“记忆装置”，保存了：
> - 返回地址（确保正确返回）
> - 调用者寄存器的保护值（通过PUSH/POP实现）
> - 局部变量和中间结果
> 这使得子程序可被多次调用、嵌套调用，实现结构化编程。

---

## 二、中断机制

**3. 描述8086CPU中断处理的基本过程，包括中断向量表的作用、中断发生时CPU的自动操作以及中断返回（IRET）与普通返回（RET）的区别。**

> **解答：**  
> **中断处理过程：**  
> 1. **中断发生：** CPU检测到中断请求（INT指令或硬件中断）
> 2. **保护现场：** CPU自动执行：
>    - 标志寄存器FLAGS压栈
>    - CS压栈，IP压栈
>    - 清除IF和TF标志（关中断）
> 3. **获取入口：** 从中断向量表（00000H~003FFH）读取中断处理程序入口地址（CS:IP）
> 4. **执行处理：** 跳转到中断服务程序
> 5. **中断返回：** 执行IRET指令，依次弹出IP、CS、FLAGS，恢复中断前状态
> **中断向量表作用：** 存放256个中断处理程序的入口地址（每个占4字节），是中断类型号到处理程序的映射表。
> **IRET与RET区别：**  
> - IRET弹出IP、CS和FLAGS，完全恢复中断前状态
> - RET仅弹出IP（近返回）或CS:IP（远返回），不恢复标志寄存器
> - IRET还会重新允许中断（恢复IF标志）

---

**4. 解释中断嵌套的原理及其实现条件，说明为什么需要中断嵌套以及如何避免中断嵌套带来的问题。**

> **解答：**  
> **中断嵌套原理：** 当CPU正在执行一个中断服务程序时，又响应更高优先级的中断请求，暂停当前中断程序，转而执行新的中断程序。
> **实现条件：**  
> 1. CPU支持中断优先级管理
> 2. 当前中断服务程序中执行了STI指令（开中断）
> 3. 有更高优先级的中断请求发生
> **必要性：** 保证紧急中断（如电源故障、硬件错误）能及时处理，提高系统实时性。
> **潜在问题与避免：**  
> - **栈溢出：** 嵌套过深导致栈空间不足 → 合理分配栈大小
> - **数据竞争：** 多个中断访问共享资源 → 使用临界区保护
> - **优先级反转：** 低优先级中断占用资源，高优先级中断等待 → 实现优先级继承
> - **死锁：** 中断相互等待资源 → 避免循环等待
> 通过合理的中断优先级设计、资源管理和栈空间分配可避免这些问题。

## 三、标志寄存器与运算控制

**5. 详细说明ZF、SF、CF、OF四个标志位在算术运算中的作用，并举例说明如何通过这些标志判断无符号数和有符号数运算的结果状态。**

> **解答：**  
> **各标志位作用：**  
> - **ZF（零标志）：** 结果为零则ZF=1。用于判断相等比较或结果是否为零。
> - **SF（符号标志）：** 结果为负则SF=1（最高位为1）。反映有符号数的正负。
> - **CF（进位标志）：** 无符号数运算时，记录最高位进位（加法）或借位（减法）。
> - **OF（溢出标志）：** 有符号数运算结果超出表示范围则OF=1。
> 
> **判断示例（以8位运算为例）：**  
> 例1：计算98H + 98H = 130H（实际为8位运算，得30H）
>   - 无符号数：98H=152，152+152=304>255，CF=1（进位/溢出）
>   - 有符号数：98H补码=-104，-104+(-104)=-208<-128，OF=1（溢出），SF=1（负）
> 
> 例2：计算7FH + 01H = 80H
>   - 无符号数：127+1=128≤255，CF=0
>   - 有符号数：127+1=128>127，OF=1（溢出），SF=1（最高位为1）
> 
> **综合判断规则：**  
> - 无符号数溢出：CF=1
> - 有符号数溢出：OF=1
> - 结果为零：ZF=1
> - 结果为负（有符号数视角）：SF=1

**6. 解释ADC（带进位加）和SBB（带借位减）指令在多精度算术运算中的应用原理，以128位加法为例说明其实现机制。**

> **解答：**  
> **ADC/SBB原理：**  
> 这两条指令在普通ADD/SUB基础上，额外加上CF标志位的值：
> - ADC: 结果 = 操作数1 + 操作数2 + CF
> - SBB: 结果 = 操作数1 - 操作数2 - CF
> **应用场景：** 当操作数位数超过寄存器宽度（如128位）时，需分段运算，CF传递段间的进位/借位。
> 
> **128位加法实现（分8个16位字进行）：**  
> 假设两个128位数分别存放在以SI和DI为首地址的8个字单元中（低字在前）：
> ```
> CLC               ; 清除CF，第一段无进位
> MOV CX, 8         ; 8个字
> ADD_LOOP:
>   MOV AX, [SI]    ; 取第一个数的当前字
>   ADC AX, [DI]    ; 加第二个数的当前字及CF
>   MOV [SI], AX    ; 存结果
>   ADD SI, 2       ; 指向下一个字
>   ADD DI, 2
>   LOOP ADD_LOOP
> ```
> **执行过程：**  
> 1. 最低字相加：ADD（无进位）或ADC（带上次进位）
> 2. 结果存回，CF记录本次进位
> 3. 下一字相加时ADC自动加上CF
> 4. 循环处理所有字
> **关键点：** CF作为“进位链”，将低字运算的进位传递到高字运算，实现任意精度算术。

## 四、寻址与内存管理

**7. 解释8086CPU分段内存管理机制的原理，包括逻辑地址到物理地址的转换公式，并说明这种设计的优缺点。**

> **解答：**  
> **分段机制原理：**  
> 8086CPU将1MB内存划分为多个逻辑段，每段最大64KB。逻辑地址表示为“段地址:偏移地址”，通过地址加法器转换为20位物理地址：
> **物理地址 = 段地址 × 16 + 偏移地址**
> 
> **转换过程：**  
> 1. 段地址左移4位（相当于×16），得到段基地址
> 2. 加上16位偏移地址，得到20位物理地址
> 3. 可寻址范围00000H~FFFFFH（1MB）
> 
> **优点：**  
> 1. **突破64KB限制：** 16位寄存器可寻址1MB空间
> 2. **逻辑组织：** 代码、数据、堆栈分段管理，提高清晰度
> 3. **重定位性：** 程序可在内存中浮动，只需调整段寄存器
> 4. **保护基础：** 为后续保护模式提供雏形
> 
> **缺点：**  
> 1. **地址重叠：** 同一物理地址可由不同逻辑地址表示（如1000:0000和0F00:1000都指向10000H）
> 2. **段寄存器开销：** 频繁加载段寄存器影响效率
> 3. **复杂地址计算：** 程序员需手动管理段寄存器
> 4. **64KB段限制：** 单段不能超过64KB
> 
> 这种设计是16位CPU在有限硬件资源下的实用方案，为后续x86架构发展奠定基础。

## 五、程序流程控制

**8. 比较JMP、CALL、LOOP、JCXZ四种流程转移指令的异同，包括它们对堆栈的影响、条件判断机制以及典型应用场景。**

> **解答：**  
> **共同点：** 都改变IP或CS:IP，实现程序流程转移。
> 
> **差异对比：**
> | 指令 | 堆栈影响 | 条件判断 | 典型应用 |
> |------|----------|----------|----------|
> | **JMP** | 无 | 无条件 | 无条件跳转、循环出口 |
> | **CALL** | 压入返回地址 | 无条件 | 子程序调用 |
> | **LOOP** | 无 | CX≠0则跳转 | 固定次数循环 |
> | **JCXZ** | 无 | CX=0则跳转 | 循环前检查、跳过空循环 |
> 
> **详细说明：**  
> 1. **JMP：** 最简单转移，不保存返回信息，用于goto式跳转
> 2. **CALL：** 自动保存返回地址，实现结构化子程序调用，必须与RET配对使用
> 3. **LOOP：** 先执行CX=CX-1，再判断CX≠0则跳转，适合已知次数的计数循环
> 4. **JCXZ：** 仅判断CX=0时跳转，常用于：
>    - 循环前检查CX是否为0，避免0次循环
>    - 配合LOOP实现复杂循环控制

### 题目1：地址计算与指令执行分析

**已知条件：**
```
DS = 2000H
ES = 3000H
SS = 4000H
BX = 0100H
SI = 0020H
DI = 0040H
BP = 0060H
SP = 1000H
```

**内存数据（十六进制）：**
```
物理地址      内容
20000H:     10 20 30 40 50 60 70 80
20008H:     90 A0 B0 C0 D0 E0 F0 00
20010H:     01 02 03 04 05 06 07 08
20018H:     09 0A 0B 0C 0D 0E 0F 10

30000H:     11 22 33 44 55 66 77 88
30008H:     99 AA BB CC DD EE FF 00

40000H:     FF EE DD CC BB AA 99 88
40008H:     77 66 55 44 33 22 11 00
```

**问题：**
1. 计算以下逻辑地址对应的物理地址：
   a) DS:[BX+SI]  
   b) ES:[DI-10H]  
   c) SS:[BP+8]  
   d) DS:120H  

2. 执行以下指令序列后，回答各小题：
   ```
   MOV AX, [BX+SI]      ; (1)
   ADD AX, 100H         ; (2)
   MOV [DI], AX         ; (3)
   SUB AX, [BX]         ; (4)
   INC WORD PTR [SI]    ; (5)
   ```
   
   a) 指令(1)执行后，AX = ?  
   b) 指令(2)执行后，AX = ?，CF = ?，ZF = ?  
   c) 指令(3)执行后，物理地址20040H-20041H的内容 = ?  
   d) 指令(4)执行后，AX = ?，SF = ?，OF = ?  
   e) 指令(5)执行后，物理地址20020H-20021H的内容 = ?

---

**题目1 参考答案：**
1. **地址计算：**
   a) DS:[BX+SI] = 2000H × 16 + (0100H + 0020H) = 20000H + 0120H = 20120H
   b) ES:[DI-10H] = 3000H × 16 + (0040H - 0010H) = 30000H + 0030H = 30030H
   c) SS:[BP+8] = 4000H × 16 + (0060H + 0008H) = 40000H + 0068H = 40068H
   d) DS:120H = 2000H × 16 + 0120H = 20000H + 0120H = 20120H

2. **指令执行分析：**
   a) 20120H处内容：从内存表看，20120H对应20000H+120H，查看20000H开始数据：
      20000H: 10 20 30 40 50 60 70 80 ... 
      120H偏移后：20120H = 20000H+120H，需要计算具体值。实际考试中会给具体数据。
      假设[20120H] = 3412H（小端存储：12 34）
      则AX = 3412H
   
   b) ADD AX, 100H: 3412H + 0100H = 3512H
      无进位，CF = 0；结果非零，ZF = 0
   
   c) [DI] = DS:0040H，物理地址 = 20040H
      AX = 3512H，小端存储：12H存20040H，35H存20041H
   
   d) SUB AX, [BX]: [BX] = DS:0100H
      物理地址20100H，假设内容为1234H
      AX = 3512H - 1234H = 22DEH
      SF = 0（最高位为0）；判断OF：3512H和1234H同号，相减不可能溢出，OF = 0
   
   e) INC WORD PTR [SI]: [SI] = DS:0020H
      物理地址20020H，假设原内容为0005H，INC后为0006H

### 题目2：标志位与运算结果分析

**已知：**
```
AX = 7FFFH
BX = 8001H
CX = 0003H
DX = 0000H
CF = 0
```

**执行以下程序段：**
```asm
ADD AX, 0001H    ; (1)
ADC BX, 0000H    ; (2) 
SUB AX, BX       ; (3)
NEG AX           ; (4)
MUL CX           ; (5)
DIV CX           ; (6)
```

**问题：**
1. 分别给出指令(1)-(6)执行后的结果和标志位状态（CF、ZF、SF、OF）
2. 如果最后执行`IDIV CX`（有符号除法）会有什么结果？说明原因。

---

**题目2 参考答案：**
1. **指令执行分析：**
   (1) ADD AX, 0001H  
       AX = 7FFFH + 0001H = 8000H  
       有符号：32767+1=32768溢出，OF=1  
       无符号：32767+1=32768无进位，CF=0  
       结果非零，ZF=0；最高位为1，SF=1  
   
   (2) ADC BX, 0000H  
       BX = 8001H + 0000H + CF(0) = 8001H  
       无变化，CF保持0，ZF=0，SF=1，OF=0
   
   (3) SUB AX, BX  
       AX = 8000H - 8001H = FFFFH（补码表示-1）  
       有符号：(-32768) - (-32767) = -1，无溢出，OF=0  
       无符号：借位，CF=1  
       结果非零，ZF=0；最高位为1，SF=1
   
   (4) NEG AX  
       AX = 0001H（-1的补码取负得+1）  
       CF通常置1（除非操作数为0），ZF=0，SF=0，OF=0
   
   (5) MUL CX  
       AX = 0001H × 0003H = 0003H  
       DX = 0000H  
       CF=0，OF=0（结果在AX中，无高位）
   
   (6) DIV CX  
       AX = 0003H ÷ 0003H = 0001H（商）  
       DX = 0000H（余数）  
       无标志位影响

2. **IDIV CX分析：**  
   此时AX = 0001H，视为有符号数+1  
   IDIV CX：+1 ÷ +3 = 0（商），余数1  
   但实际IDIV要求被除数为32位（DX:AX）  
   若DX:AX = 00000001H（+1），除以3得商0，余数1  
   商（AX）= 0000H，余数（DX）= 0001H

### 题目3：程序填空（字符串操作）

**功能：** 将DS段中以SI为首地址的字符串（以0结尾）中的小写字母转换为大写字母，其他字符不变。

**已有程序框架：**
```asm
DATA SEGMENT
    STRING DB 'Hello, World! 2023', 0
DATA ENDS

CODE SEGMENT
    ASSUME CS:CODE, DS:DATA
START:
    MOV AX, DATA
    MOV DS, AX
    MOV SI, OFFSET STRING
    CALL TO_UPPER
    MOV AH, 4CH
    INT 21H

; 子程序：将字符串中的小写字母转大写
TO_UPPER PROC
    PUSH AX
    PUSH BX
    PUSH SI
    MOV BX, SI          ; BX指向字符串
    
NEXT_CHAR:
    MOV AL, [BX]        ; (1) 取字符
    CMP AL, 0           ; (2) 判断是否结束
    JE FINISH
    CMP AL, 'a'         ; (3) 判断是否小写字母
    JB NOT_LOWER
    CMP AL, 'z'
    JA NOT_LOWER
    SUB AL, 20H         ; (4) 小写转大写
    MOV [BX], AL        ; (5) 存回
    
NOT_LOWER:
    INC BX              ; (6) 指向下一字符
    JMP NEXT_CHAR
    
FINISH:
    POP SI
    POP BX
    POP AX
    RET
TO_UPPER ENDP

CODE ENDS
    END START
```

**问题：**
1. 请填写(1)-(6)处的指令注释
2. 如果要将功能改为"删除字符串中的所有数字字符"，应如何修改？写出关键修改部分

---

**题目3 参考答案：**
1. **填空：**

   (2) ; 检查是否字符串结束（遇到0）
   (3) ; 检查是否小于'a'
   (4) ; 转换为大写（小写字母ASCII减20H）
   (5) ; 将大写字母存回原位置
   (6) ; 指针指向下一个字符

2. **修改为删除数字字符的关键代码：**

NEXT_CHAR:
    MOV AL, [BX]
    CMP AL, 0
    JE FINISH
    CMP AL, '0'
    JB NOT_DIGIT

SHIFT_LOOP:

    RET
SHIFT_LEFT ENDP

### 题目4：简单程序编写

**功能要求：**
编写一个完整汇编程序，实现以下功能：
1. 从DATA1开始的10个字节数据中找出最大值
2. 将最大值存入MAX单元
3. 计算DATA1中所有数据的和（16位和）
4. 将和存入SUM单元

**数据结构：**
```asm
DATA SEGMENT
    DATA1 DB 23, 45, 12, 67, 89, 34, 56, 78, 90, 11
    MAX   DB ?
    SUM   DW ?
DATA ENDS
```

**评分标准：**
- 正确初始化段寄存器 (2分)
- 正确实现最大值查找 (5分)
- 正确实现求和计算 (5分)
- 正确存储结果 (3分)
- 程序结构完整、有注释 (5分)

---

**题目4 参考答案：**
```asm
DATA SEGMENT
    DATA1 DB 23, 45, 12, 67, 89, 34, 56, 78, 90, 11
    MAX   DB ?
    SUM   DW ?
DATA ENDS

CODE SEGMENT
    ASSUME CS:CODE, DS:DATA
START:
    ; 初始化段寄存器
    MOV AX, DATA
    MOV DS, AX
    
    ; 初始化
    MOV SI, OFFSET DATA1  ; 数据指针
    MOV CX, 10            ; 循环次数
    MOV AL, [SI]          ; 假设第一个为最大值
    MOV MAX, AL           ; 存初始最大值
    MOV BX, 0             ; 用于累加和（16位）
    MOV AH, 0             ; 清零AH，用于字节扩展
    
    ; 循环处理每个数据
NEXT:
    MOV DL, [SI]          ; 取当前数据
    
    ; 更新最大值
    CMP DL, MAX
    JLE NOT_MAX           ; 如果不大于当前最大值
    MOV MAX, DL           ; 更新最大值
    
NOT_MAX:
    ; 累加到和
    MOV DH, 0             ; 字节扩展为字
    ADD BX, DX            ; 累加到BX
    
    ; 准备下一次循环
    INC SI
    LOOP NEXT
    
    ; 保存结果
    MOV SUM, BX
    
    ; 程序结束
    MOV AH, 4CH
    INT 21H
    
CODE ENDS
    END START
```

## 考试建议

### 分析计算题答题技巧：
1. **地址计算：** 牢记公式：物理地址 = 段地址×16 + 偏移地址
2. **标志位判断：**
   - CF：无符号数溢出（加法进位/减法借位）
   - OF：有符号数溢出（正+正=负 或 负+负=正）
   - ZF：结果为零
   - SF：结果最高位为1（有符号数为负）
3. **指令影响：** 记住哪些指令影响标志位（ADD/SUB影响所有，MOV不影响等）
