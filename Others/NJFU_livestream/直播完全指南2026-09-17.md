## 一.直播的原理

1. 直播的基本链路是：先用 SRS 软件搭建直播服务器，再通过 OBS Studio 完成画面切换，最后将画面推送到 SRS 服务器。

2. **操场直播**：操场主席台的计算机无法直接连接互联网，但它与学校其他区域（如宿舍，教学楼4号楼、行政楼除外）处于同一校园网中。因此需要借助学校其他区域的网络，将直播信号做二次转发，才能最终推送到互联网。

3. **教学主楼A报告厅直播**：报告厅可以直接连接互联网，因此使用 OBS Studio 直接输出即可，无需二次转发。

## 二.直播的准备

### 一般性准备

1. **相机一台**：建议关闭自动对焦，使用手动对焦（MF），将焦点固定在舞台上。

2. **假电池一块**：原则上需要使用假电池以延长相机的连续录制时间。不过实测发现，唯卓仕的 FZ100 电池可以通过 micro-USB 接口持续供电，实现等效于假电池的功能。因此推荐索尼 α1、α7III、α7IV、α7RIII、α7RⅣ、α7RV、α9、α9II、α9III、α6600、α6700、α7SIII、FX3、FX2 等机型用户使用唯卓仕电池。**佳能用户注意：必须合上电池仓盖后相机才能开机。**

3. **笔记本电脑不少于1台**：原则建议使用单显卡的笔记本电脑；若笔记本电脑支持独显直连，或可通过省电模式关闭独立显卡，也可使用。推荐单显卡全能本或 MacBook。

```
如有不止一台笔记本电脑，请阅读以下说明：

1. 用于直播画面切换 / 在宿舍进行直播画面转发的笔记本电脑，必须是单显卡、或支持显卡直连、或支持关闭独立显卡的机型。

2. 安装 SRS 的笔记本电脑应具备千兆或万兆网口以保证足够网速，并拥有较强的 CPU 性能。
```

4. **三脚架一台**：越高越好（2024年末迎新晚会使用了一台 2.2 米高的三脚架）。

5. **路由器一台**：校区有一台小米 AX3000T 路由器，如有需要，请联系时任招生办公室助理团淮安新媒体部部长借用。

6. **操场直播专用**：请准备足够长的插线板和网线（校区现有一根30米绿联 CAT-5e 网线、2根20米插线板，如需要可联系时任招生办公室助理团淮安新媒体部部长借用）。

### 特殊性准备

1. 如使用 APS-C 画幅微单相机，建议提前一天进行持续性压力测试，防止机身过热关机。可通过购买退热贴、散热背夹等方式延长录制时间。一般情况下，如果通过 USB 接口进行视频输出，即使是索尼 α6700 也不会出现过热问题；但如果使用采集卡输出，务必提前进行压力测试。

2. 由于通过 USB 接口输出的画面质量普遍较低，对于带有 HDMI / micro-USB 接口的相机，建议通过「采集卡 + HDMI 线」连接笔记本电脑，并在相机机内进行相关设置，使其输出全尺寸 4K 画面。

3. 可使用 DJI OSMO Pocket3、DJI Mavic Air3 等设备实现多机位直播。

4. 可使用 DJI Mic（第二代）获取更高质量的音频。需注意：在2024年10月迎新晚会直播中，由于舞台到直播机位之间距离较长，DJI Mic（第二代）出现了信号断联的故障。

5. 如需将直播画面同时推送至多个平台，请安装兼容 OBS 的多路推流插件。

## 三.直播的配置

1. **启动 SRS**：使用管理员权限打开 SRS 客户端，后续操作期间保持其在后台运行，请不要关闭。（再次提醒：安装 SRS 的笔记本电脑应具备千兆或万兆网口，并拥有较强的 CPU 性能。如果在操场直播，这台电脑建议放置在操场上。一般情况下推荐使用 Windows 系统。）

![srs_software](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic3.png?raw=true)

2. **设置路由器**：登录 SRS 电脑所连接路由器的后台管理页面。小米路由器默认登录地址为 `192.168.31.1`，其他路由器请查看机身背面的贴纸或网上查阅相关资料。这里以刷入 OpenWRT 系统的小米路由器为例，与官方小米路由器系统略有不同，但原理相似。

3. **记住路由器的 IP 地址**，这对后续配置至关重要。

![ip](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic4.png?raw=true)

4. **查看电脑 IP**：打开命令提示符。Windows 系统：同时按住 `Windows 徽标键 + R`，输入 `cmd` 回车；在命令提示符中输入 `ipconfig`，即可看到如下所示的内容。找到"IPv4 地址"，其前 3 位应与路由器登录地址相同，即对于小米路由器，一般为 `192.168.31.*`。

![ipconfig](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic5.png?raw=true)

5. **配置端口转发**：进入路由器设置的高级设置 / 防火墙，找到端口转发（Port Forwarding），创建一条规则，将安装 SRS 软件的电脑 IP 作为内网 IP 进行映射。如无特殊需求，建议直接开启 DMZ（转发全部端口）。其余设置保持默认即可。

![dmz](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic6.png?raw=true)

6. **给直播机位编号**：建议将编号提前写在一张纸上，贴在运行 OBS 切换输出的笔记本电脑前。例如 2024 年迎新晚会直播使用了如下设备：

```
1. ILCE-6700   编号：01
2. DJI Mavic Air3   编号：02
3. DJI Mavic Air2   编号：03
4. DJI Osmo Pocket3   编号：04
5. Canon Eos R8   编号：05
```

另外，还需要对以下画面编号：

```
6. 直播画面输出   编号：00
7. 音频输入信号(如有必要)   编号：06
```

7. **设置转发笔记本电脑（用于校区内二次转发）**：这台电脑放置在校园其他区域（一般建议放在非12栋以外的宿舍楼，且网口为8线全通），专门负责将画面转发至外网。原则上要求单显卡机型，具体原因见常见问题。

在 OBS 中创建一个新场景，并新建一个媒体源：

![new1](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic7.jpg?raw=true)

![new2](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic8.jpg?raw=true)

取消勾选"本地文件"，在"输入"中填写 IP 地址，格式为：`rtmp://室外路由器ip地址/livestream/直播画面输出的机位号`

（注意：下方配图中的地址有误，正确的格式应该是 `rtmp://10.58.3.161/livestream/*`）

![new3](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic9.png?raw=true)

回到 OBS 主界面，点击"转场动画"即可看到输出画面。如果未见输出画面，请参考本文末尾"常见问题2"。之后点击"设置"：

![new4](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic10.png?raw=true)

点击"直播"，将从平台获取的推流地址和密钥填入对应位置。回到主界面，点击"开始直播"和"开始录制"：

![new5](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic11.png?raw=true)

8. **设置外场画面切换笔记本电脑**：这台电脑负责画面切换，可以与 SRS 电脑是同一台，也可以分开；受性能限制，建议使用 2 台以上的笔记本电脑。

接下来的配置中，所填 IP 地址永远是 `192.168.31.*`（以小米路由器为例），即 SRS 服务器的内网地址。此后的操作无需再使用 `10.*.*.*` 开头的路由器外网 IP。

为每一个机位创建一个场景：使用 USB 线或采集卡将相机连接笔记本电脑，通过"视频采集设备"创建视频源。对于大疆设备，与拉流操作类似，可在 DJI Go 4、DJI Fly、DJI Mimo 等软件的直播选项中填写推流地址，然后在 OBS 中通过"媒体源"拉流。

切换画面时，点击"转场动画"即可：

![trans](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic12.png?raw=true)

图层覆盖规则：同一场景中，上方的输入会覆盖下方的输入。如需将多个画面混合，请将想显示的图层移到上方。

音频相关：如果使用了额外的音频采集设备，或希望在切换画面时保持音频不切换，请在右侧的混音器中修改声音的输入来源。

**建议**：一场直播中尽量只使用唯一的声音来源，声音不随画面切换而切换。通常建议使用 DJI Mic（第二代）等高质量设备收音，或直接以相机作为声音来源。

推流设置：与前述步骤类似，点击"设置"→"直播"，填入从平台获取的推流地址和密钥，回到主界面点击"开始直播"和"开始录制"。也可在"设置"→"输出"中修改直播输出的视频码率。

切换画面：只需点击"转场动画"，或拖动快速转场下方的滑轨即可。

**关于码率的建议**：1080P 通常需要不低于 20M（20000K）码率才能获得较为可用的画质，但直播往往承受不了如此大的带宽。因此建议先设置一个较高值（通常不高于 10000K），如出现显著卡顿再做调整。直播开始后请尽量不要改动码率，2024 年 10 月迎新晚会最终推送码率为 4M（4000K），出现了轻度卡顿。如果仍想获得较好的画质，建议在直播机位旁另放一台相机全程录像。对于 DJI 设备，设置较高的码率一般不会出现严重卡顿。

9. **直播录像的转码**：OBS Studio 录制的直播回放通常是 mkv 格式，转码方法如下：

```bash
ffmpeg -i 输入.mkv -c copy 输出.mp4
```

## 四.常见问题

1. **老师要求设置延迟推送，并在出现问题时及时切断直播画面，如何操作？**

答：建议至少使用 2 台笔记本电脑。将直播输出画面推送至 SRS 服务器后，通过第二台笔记本电脑拉取视频，并在"设置 → 高级 → 直播延迟"中设置延迟。如果出现突发问题，请在延迟时间内登录微信视频号等平台关闭直播推流，然后再关闭其他设备。

![SRS_Video](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic1.png?raw=true)

2. **一切配置完毕，但 OBS Studio 拉取不到视频画面，如何处理？**

答：这种情况往往是因为这台笔记本电脑拥有 2 张显卡。理论上，采用单显卡笔记本电脑可以避免此类问题。排查方法：通过系统的终端 / cmd 输入 ffmpeg 命令，语法格式为 `ffplay rtmp://*/livestream/*`。如果 ffmpeg 可以正常读取，则很可能是双显卡输出导致的兼容性问题。

临时解决方案：使用 ffmpeg 将视频全屏播放，然后采用屏幕采集方式获取视频。

![ffmpeg](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic14.png?raw=true)

![can_not_read_video](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic2.png?raw=true)

长期解决方案：开启显卡直连、关闭独立显卡，或者更换电脑。

3. **SRS 出现如下图所示的报错，如何解决？**

![srs](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic17.jpeg?raw=true)

问题分析：SRS 正在尝试启动多个模块（如 RTMP、HTTP-FLV、WebRTC 等），每个模块都会监听特定端口（常见端口包括 1935、1985、8080、8000、10080）。`errno=112 + "Address already in use"` 表示端口已被占用，SRS 无法绑定这些端口。请检查是否开启了多个 SRS 服务器，如果是，请关闭多余的实例。

常见解决办法：

Windows 系统：在 cmd 中输入 `netstat -ano | findstr :xxxx`（将 xxxx 替换为日志中报错的端口号），得到形如 `TCP    0.0.0.0:1935     0.0.0.0:0     LISTENING     1234` 的输出，最后一列为占用该端口的进程 PID。然后输入 `taskkill /PID 1234 /F` 结束该进程。如果该方法仍然无效，建议重启电脑。

4. **SRS 出现大量红色报错，但没有终止进程，为什么？**

常见原因：没有使用管理员权限打开 SRS。

5. **没有预览画面，OBS 不断提示"正在重连"，如何解决？**

![obs](https://github.com/fang50253/NJFU_CS_Note/blob/main/Others/pic/live/pic18.jpeg?raw=true)

2025 年末迎新晚会的解决办法是：重新登录微信视频号后台，重新获取推流地址。
